02 A SMALL CLIENT API

Wire it into
your own app.

Import the ES module from this repository, prepare a local engine, then subscribe to transcript and stable chunk updates. Nothing here requires a transcription server.

Read the API contract ↗
ES MODULE · BROWSER
import { createTranscriber } from "https://YOUR-USER.github.io/YOUR-REPO/src/index.js";

const finalText = document.querySelector("#final-transcript");
const liveText = document.querySelector("#live-preview");
const prepareButton = document.querySelector("#prepare");
const startButton = document.querySelector("#start");
const stopButton = document.querySelector("#stop");

const speech = createTranscriber({
  engine: "whistle-local", // or "chrome-local"
  language: "en-US",
});

speech.on("transcript", ({ text, preview }) => {
  finalText.textContent = text;
  liveText.textContent = preview;
});

speech.on("chunk", ({ text, sequence }) => {
  console.log("Stable chunk", sequence, text);
});
speech.on("error", ({ code, message }) => console.error(code, message));

prepareButton.addEventListener("click", async () => {
  await speech.prepare(); // call from this user action
  startButton.disabled = false;
});
startButton.addEventListener("click", () => void speech.start());
stopButton.addEventListener("click", () => void speech.stop());

For a production app, serve the Whistle module, worker, WASM, and model files from the same origin as your app.
